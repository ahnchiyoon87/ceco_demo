CECO 데모 시스템 구조

반응 공정 한 줄을 가상으로 돌리고, 공장(OT)·완충지대(DMZ)·사무(IT) 세 구역으로 나눠 계측 → 이상 탐지 → 경보 → AI 대응 → 승인된 작업 요청 → 설비 반영까지 한 번에 보여 주는 학생 수준의 산출물 예시다. 모든 부품은 무료 공개 제품이고 도커 컴포즈 한 벌로 뜬다.

그림의 부품 {{NP}}개와 선 {{NL}}개에 번호를 붙였다. 아래 본문의 같은 번호가 같은 것을 가리킨다.

그림 읽는 법전체 그림구역과 연결 원칙네 흐름부품 {{NP}}개선 {{NL}}개줄이거나 고른 것

그림 읽는 법

● 이 쪽이 연결을 연다(TCP를 먼저 건다).
화살표 데이터가 흐르는 방향. 양쪽 끝에 있으면 오고 간다.
빨간 굵은 선 작업 요청 길. 검사 1·2·3은 요청을 거르는 세 겹(게이트웨이 → OT 수신기 → PLC).
회색 점선 감시 지표. 공정 데이터는 싣지 않는다.
긴 점선 기동 때 한 번 도는 도우미, 파일 전달. 점선 상자가 도우미다.
상자 위 작은 회색 표 감시 지표를 긁는 선. 선을 그리지 않고 긁는 쪽(“긁음”)과 대상에 같은 번호를 붙였다.
검은 막대 구역 라우터. 막대 위 숫자는 라우터가 넘겨 주는 포트.

좁은 화면에서는 그림을 옆으로 밀어 본다. 한 선이 여러 곳으로 갈라지면(부채꼴) 번호는 하나다.

구역과 연결 원칙

OT · 공장 망

{n:plc}~{n:otag}, {n:prov}(현장 {n:sim}과 붙어 있다). 기계와 가까운 부품. 밖과 연결이 끊겨도 계측·화면·제어·안전이 그대로 돈다. 공장 안 부품은 모두 {n:hub}에만 연결한다.

DMZ · 완충 망

{n:dmzb}~{n:dmzp}. 공장과 사무가 직접 만나지 않고 여기서만 주고받는다. DMZ 부품은 어느 쪽으로도 새 연결을 열지 않는다.

IT · 사무 망

{n:kafka}~{n:bus}과 도우미. 분석·기록·AI·업무. 공장에는 요청만 보낼 수 있고, 그것도 DMZ 게이트웨이를 거친다.

  1. 연결은 신뢰가 높은 쪽이 연다. OT → DMZ는 {l:bridge_out}·{l:otag_rw} 두 가지뿐이고, IT → DMZ는 {l:coll_sub}·{l:coll_disp}(같은 계정), {l:coll_gw}, {l:graf_dmzi}·{l:ai_dmzi}, {l:prom_fed}이다.
  2. DMZ → OT, DMZ → IT, IT → OT로 새 연결은 없다. {n:router} 구역 라우터가 허용 목록 밖을 세고 버리며, 응답은 이미 열린 연결로만 돌아간다.
  3. DMZ의 요청이 OT로 들어오는 것도 OT가 연 브리지 {l:bridge_in}으로 가져오는 방식이다. 연결 방향(●)과 데이터 방향(화살표)이 다를 수 있어 그림에 둘을 따로 표시했다.
  4. MQTT 계정마다 읽기·쓰기 토픽을 ACL로 좁혔다. 예: IT 수집기는 DMZ에서 표시 토픽 하나에만 쓸 수 있다.

줄이거나 고른 것

  • 세 구역은 망 세 개와 라우터 규칙 {n:router}로 흉내 냈다. 실제 공장은 방화벽 장비(응용 계층 검사 포함)를 둔다.
  • 브리지는 연결 하나로 양방향({l:bridge_out}·{l:bridge_in})이고, TLS와 강한 인증은 뺐다. 2026 연결 원칙은 DMZ 복제에 단방향·강한 인증을 권한다(교육용 축소).
  • IT는 DMZ 원시 사본 {n:dmzi}을 조회하고, DMZ 브로커 {n:dmzb}도 직접 구독한다. 지침은 DMZ 히스토리언을 강한 인증 HTTPS API로 조회하라고 권한다.
  • MQTT 브로커를 두 개({n:hub}·{n:dmzb}) 둔 것은 공장 화면이 DMZ 없이도 돌아야 한다는 격리 원칙 때문이다. 현업에는 DMZ 브로커 하나에 공장이 밖으로 접속하는 방식도 흔하다.
  • REMOTE_AUTO 자동 수용은 "분석 시스템은 관찰만 하고 운전을 바꾸지 않는다"는 2026 지침 문장과 부딪힌다. 검증을 거친 자동 반영을 허용하는 NAMUR NE 178 쪽을 택했고, 안전(인터록·범위·되읽기)은 PLC {n:plc}가 지킨다.
  • DMZ에 원시값을 7일 저장한다. "DMZ는 데이터를 영구 저장하지 않는다"는 Cisco CPwE와 달리 DMZ 히스토리언을 두는 2026 지침 쪽을 택했다.
  • 대시보드를 IT에 둔 것은 지침에 없는 우리 판단이다. 운전원 화면 {n:fuxa}는 공장 안에 둔다.
  • 작업 요청을 보내는 외부 시스템은 AI({n:ai})와 MES 흉내({n:coll} 스트림 ⑧) 둘이다. 요청 필드(job_order_id·work_master_id)는 ISA-95 작업 지시를 흉내 냈고, 만료 필드는 표준에 없는 확장이다.
