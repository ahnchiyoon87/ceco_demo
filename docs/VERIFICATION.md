## 실측 수치

### 성능

| 지표 | 값 |
|---|---|
| 센서 유입 | 12 건/초 |
| ONNX 추론 지연 | **0.16 ~ 0.18 ms** |
| 정상 운전 오탐 | 90초간 **0건** |
| Prometheus 타깃 | 7/7 up |

### 오토인코더 판별력 (학습 시 자가검증)

| 시나리오 | 평균 재구성오차 | 탐지율 |
|---|---|---|
| 정상 | 0.021 | 0.5 % |
| drift | 55.8 | 100 % |
| bearing_wear | 146.1 | 100 % |
| spike | 17.4 | 100 % |
| noise | 0.031 | 3.6 % |

`noise` 가 낮은 것은 설계대로입니다 — 분산 급증은 Tier-1 롤링 Z-Score 의 담당이며
오토인코더가 반응하지 않는 것이 정상입니다.

## 검증되지 않은 것 (한계)

| 항목 | 이유 |
|---|---|
| 고빈도 부하 (수만 TPS) | 단일 브로커·단일 TaskManager 구성. 파티션과 슬롯을 늘려야 함 |
| 다중 노드 HA | Kafka 1 브로커, Flink JM 1대. 장애 격리는 검증했으나 HA 페일오버는 미검증 |
| TLS / 인증 | 데모 구성이라 평문. EdgeX 는 `EDGEX_SECURITY_SECRET_STORE=false` |
| 실제 PLC 연동 | 시뮬레이터로 대체. Modbus/TCP 표준을 따르므로 주소만 바꾸면 실장비 연결 가능 |
| 장기 운영 안정성 | 시간 단위 연속 운전은 확인, 일/주 단위는 미검증 |
