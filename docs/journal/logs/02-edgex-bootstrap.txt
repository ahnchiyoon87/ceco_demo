[2] 첫 기동 — postgres 실패

$ rtk proxy docker logs edgex-postgres | tail -5
2026-09-16 07:57:43.520 UTC [1] FATAL:  could not create lock file "/var/run/postgresql/.s.PGSQL...
initdb: warning: enabling "trust" authentication for local connections

원인: 공통 앵커의 read_only + user:2002:2001 조합으로 postgres 엔트리포인트가
      /run/postgresql 을 만들지 못함
해결: postgres 는 공통 앵커를 쓰지 않고 별도 정의 (엔트리포인트가 root 로 시작 후 강등)

[4] 디바이스 프로파일 거부

$ rtk proxy docker logs edgex-device-modbus | grep ERROR
level=ERROR source=profiles.go:163 msg="Failed to YAML decode Device Profile from
  /res/profiles/ar100.profile.yaml: device command's ReadWrite permission 'RW'
  doesn't align the device resource"
level=ERROR source=init.go:118 msg="Failed to load devices: 1 error occurred:
  * add Device failed: device profile 'AR100-Reactor-Line' not found during
  validating device 'reactor-line-01'"

원인: Control 커맨드(RW)에 읽기전용 Interlock 리소스 포함
해결: 읽기전용 리소스를 Status(R) 커맨드로 분리

$ python3 gen_profile.py
생성 완료: deviceResources=21  autoEvent=1000ms
  AllSensors rw=R  members=12 perms=['R']  OK
  Control    rw=RW members= 7 perms=['RW'] OK
  Status     rw=R  members= 2 perms=['R']  OK

msg="Private configuration loaded from the Configuration Provider. No overrides applied"

[8] Store-and-Forward 설정이 일부만 반영

msg="Starting StoreAndForward Retry Loop with 5m0s RetryInterval and 10 max retries."
                                              ^^^^                  ^^
                                              설정한 5s / 1000 이 아님

$ docker run --rm --network iiot curlimages/curl:latest -s \
    "http://edgex-core-keeper:59890/api/v3/kvs/key/edgex?keyOnly=true" | \
    python3 -c "... grep StoreAndForward ..."

총 키: 217
  edgex/v4/core-common-config-bootstrapper/app-services/Writable/StoreAndForward/Enabled
  edgex/v4/core-common-config-bootstrapper/app-services/Writable/StoreAndForward/MaxRetryCount
  edgex/v4/core-common-config-bootstrapper/app-services/Writable/StoreAndForward/RetryInterval
  edgex/v4/app-mqtt-export/Writable/StoreAndForward/Enabled          ← 이것만 서비스 설정

원인: RetryInterval / MaxRetryCount 는 공통 설정에 존재.
      서비스 private config 에 없는 키의 오버라이드는 조용히 무시됨
해결: 부트스트래퍼에 APP_SERVICES_ 접두사로 주입

msg="Starting StoreAndForward Retry Loop with 5s RetryInterval and 1000 max retries."
