의도(Why & Value)
CECO 시연과 피지컬 AI 교육을 준비할 강사를 위해, 공유 자료를 종합해 판단하고 기존 시스템 위에 AI 레이어를 얹어 실제 기동 가능한 수준까지 만든다.

작업요령과 컨텍스트
캡스톤 특강 준비로 CECO 작업은 아직 시작하지 못했다. 오늘은 이 작업을 최우선으로 두고 하루 전체를 집중한다.
공유된 피지컬 AI 자료를 조합해 읽고, 현재 과정에 무엇을 반영하고 제외할지 판단한다.
전문가 컨펌 베이스인 L1~L6은 유지하고, L7~L9에 AI 레이어를 새로 쌓아 CECO 시연이 실제로 기동되게 한다.
구현 판단을 제조 시나리오·AI 스택·15시간 온라인 이론 실라바스까지 연결한다.

인수조건(DoD)
1. 공유 자료의 내용이 반영·참고·제외로 구분되고 판단 이유가 있다.
2. L1~L6은 유지되고 L7~L9 AI 레이어가 연결된다.
3. CECO 시연본이 중단 상태에서 시작해 핵심 제조 시나리오를 끝까지 실행한다.
4. RAG·그래프DB·데이터패브릭·온톨로지와 사람 승인 단계의 역할이 시연에서 드러난다.
5. AI 스택과 제조 시나리오가 현재 커리큘럼과 실습 흐름에 연결된다.
6. 온라인 이론의 주제별 시간이 나뉘고 합계가 15시간이다.

## CECO 후속 필수 개선 — 2026-09-22

사용자 피드백: “5, 6 화면도 보강이 필수일것같음 todo로 기억하셈”. 아래 항목은 미완료이며, 제출 이미지에서 제외하는 것으로 개선을 대신하지 않는다.

- [ ] **5번 자료 등록·지식 구축 UI 보강**: 자료를 왜 등록하는지, AI가 무엇을 추출했는지, 사람이 어떤 관계를 검토하고 게시하는지 한눈에 이해되도록 개선한다. 원본 자료 → 관계 후보 → 검토 → 그래프 반영의 연결과 현재 단계·결과를 명확히 보여준다. 빈 상태·처리 중·실패·재시도 상태도 실제 화면에서 검증한다.
- [ ] **6번 SCADA 공정 감시 UI 보강**: 공정·설비 배치, 주요 센서값·단위, 운전 상태·알람의 시각적 우선순위와 가독성을 개선한다. 기존 SCADA의 데이터 연결·제어 동작을 보존하고, 값 갱신·통신 단절·알람 상태가 구분되는지 실제 화면에서 검증한다.
- [x] **제출 이미지 재구성**: 메뉴별 화면 나열 대신 AI 도우미의 사건 확인 → 근거 조회 → 대응안 제시 → 사람 승인·결과 확인 과정을 핵심 구도로 촬영한다. 실제 화면과 저장된 기록만 사용하며, 저장 기록 조회와 새 실행을 구분한다. 전체 화면만 고집하지 않고 읽기 좋은 작업 영역을 선택한다. 1920×1080, 장당 2MB 이상 원본 이미지를 별도 폴더에 제공하고 실제 이미지를 검수한다.

완료 기준: 각 화면의 목적·현재 상태·다음 행동이 설명 없이 파악되고, 잘림·겹침 없이 읽히며, 실제 기능과 실패 상태 확인 근거가 남는다. 위 체크박스는 구현·검증 후에만 완료 처리한다.
