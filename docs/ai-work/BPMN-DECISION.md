# BPMN 채택 판단 — 현재 전시 범위에서는 실행 엔진을 추가하지 않음

판단일: 2026-09-21. 사용자 지시는 BPMN을 필수로 지정하지 않았으며 재사용 이익과 복잡성에 따라 선택하도록 했다.

현재 업무는 한 사건의 조사, 대응안 검토, 승인/반려, 제한된 시뮬레이터 조치, 확인 또는 미해결 처리다. Process GPT에서 가져온 영속 HITL과 LangGraph의 명시적 상태 흐름, PostgreSQL 사건/조치 기록으로 이를 실행하고 있다. 사용자에게 필요한 대기 상태·담당 검토·근거·실행 결과는 UI에 제공한다.

참조한 Process GPT는 더 넓은 업무 프로세스를 다루며 BPMN 추출·편집 코드를 포함한다. 현재 업무에서는 별도 BPMN XML 저장, 편집기, 실행 해석 계층을 추가해도 제조 판단의 근거가 늘어나지 않는다. 두 실행 상태의 동기화와 복구 책임이 추가된다. 따라서 이번 완성본에서는 BPMN 실행/편집기를 도입하지 않는다. 이는 학생이 BPMN을 할 수 없어서 내린 결정이 아니다.

여러 역할의 병렬 정비, 자재 구매, 작업 지시, 기한과 에스컬레이션, 업무 담당자의 프로세스 편집이 실제 요구가 되면 BPMN을 다시 검토한다. 현재 화면의 단계 표시는 업무 상태이며 BPMN 엔진 실행이라고 표현하지 않는다.

이 결정은 목표의 업무 흐름을 줄이지 않는다. 승인/반려·재시작·중복 실행 방지·불확실한 결과 처리는 계속 필수다.
