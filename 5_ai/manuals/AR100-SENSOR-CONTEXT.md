# AR-100 센서의 계측 대상과 조절 영향

대상은 site AR-100, device reactor-line-01인 가상 반응기 라인이다. 아래 관계는 현재 시뮬레이터 코드와 화면 생성 코드의 의미를 정리한 것이며 실제 공장의 센서 설치 도면이나 승인 운전 절차가 아니다.

## 코드에서 직접 확인한 계측 대상

원료탱크 TK-101의 액위를 LT-101이 나타낸다. 0_plant/simulator/plant.py에서 LT-101은 feed_vol을 원료탱크의 면적과 높이로 나누어 계산한다. TK-101이라는 화면 식별자는 2_ot/hmi-fuxa/dashboard.py의 원료탱크 표시와 대응한다.

반응기 R-101의 액위를 LT-102, 온도를 TT-101, 압력을 PT-101, pH를 pH-101, 전도도를 CT-101이 나타낸다. 0_plant/simulator/plant.yaml은 LT-102·TT-101·PT-101·pH-101을 각각 반응기 계측값으로 정의한다. 0_plant/simulator/plant.py는 CT-101을 반응기 pH와 temp_c를 사용해 계산한다. 따라서 이 프로젝트의 CT-101은 반응기 유체의 전도도를 나타내는 가상 계측값이다.

교반기 M-101의 모터 전류는 IT-102, 진동은 VT-101이다. 공급펌프 P-101의 모터 전류는 IT-101이고 공급 유량은 FT-101이다. 이 관계는 기존 설비 맥락 문서와 0_plant/simulator/plant.yaml 및 plant.py의 읽기값 산출에 함께 명시되어 있다.

이 문서에서 설비와 센서를 연결하는 것은 가상 공정의 계측 대상 관계를 설명한다. 물리 센서의 실제 부착 위치, 제조사 규격 또는 현장 교정 이력을 증명하지 않는다.

## 소속과 구분해야 하는 두 계측값

TT-102는 재킷 온도이며 0_plant/simulator/plant.py의 jacket_c 값을 읽는다. jacket_c는 반응기 온도와 히터 가동률에 따라 변한다. 히터 HX-101은 이 온도에 영향을 주지만, 코드만으로 TT-102가 히터 본체의 온도 센서라고 확정할 수 없다. 히터 본체 온도와 재킷 온도를 같은 값으로 설명하지 않는다.

FT-102는 반응기에서 나가는 배출 유량 q_out이다. q_out은 배출밸브 CV-101의 설정 개도와 반응기 수위로 계산된다. 밸브가 유량에 영향을 주는 것과 유량 센서가 밸브에 소속된다는 것은 다른 주장이다. 코드에는 실제 배관상 센서 설치 위치가 정의되어 있지 않다.

따라서 TT-102와 FT-102의 직접 설비 소속이 필요한 경우 재킷·배출 배관을 어떤 설비 범위로 모델링할지 별도 정의가 필요하다. 관계 개수를 채우기 위해 HX-101 또는 CV-101의 HAS_SENSOR로 자동 확정하지 않는다.

## 관계를 사용할 때의 한계

센서 소속이 연결되어도 해당 설비의 고장 원인이 확정되지 않는다. pH와 전도도가 함께 바뀌는 것은 현재 시뮬레이터가 두 값을 연계해 계산하기 때문이며, 실제 공장에서 모든 전도도 변화의 원인이 pH라는 뜻이 아니다.

재킷 온도와 히터의 영향 관계 역시 설비 조작 권한을 부여하지 않는다. 운전 명령은 별도의 허용된 제어 요청과 상태 확인 절차를 거친다.
